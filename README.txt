百人一首 暗記の庭 — 完全版

【ファイル】
index.html : ホーム・遊び方選択・ゲーム画面
style.css  : 季節に合わせたデザインとレスポンシブ表示
script.js  : 小倉百人一首100首、出題処理、五色札分類、季節判定

【使い方】
1. ZIPを解凍します。
2. index.html をブラウザで開きます。
3. ホーム画面の「遊び方を選ぶ」から出題形式・札の種類・出題順を選びます。
4. 「この設定で始める」でゲームを開始します。

【季節テーマ】
端末の日付を使って自動判定します。
春：3〜5月（桜）
夏：6〜8月（夏祭り）
秋：9〜11月（紅葉）
冬：12〜2月（お正月）

【出題形式】
・おまかせ（混合）
・4択問題
・文字入力
・札選択

【五色札】
青・桃・黄・緑・橙を各20首、合計100首に分類しています。
インターネット接続がなくても基本機能は動作します。フォントは接続環境によりシステム標準に切り替わる場合があります。
